# Glanz Systems — Modern Web Platform Redesign

A high-performance, precision-engineered industrial automation web platform for **Glanz Systems** (Ahmedabad, Gujarat).

## Technology Stack
- **Structure**: Semantic HTML5
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`) with custom `@theme` tokens
- **Logic**: Vanilla JavaScript (ES6+ Modules)
- **Animations**: GSAP & GSAP ScrollTrigger
- **Typography**: Space Grotesk (Headings), Plus Jakarta Sans (Body), JetBrains Mono (Technical Data)
- **Icons**: Lucide Icons
- **Design Ratio**: 70% Light Industrial UI / 30% Dark Focus & CTA Sections
